专注助手隐私政策

更新日期：2026 年 10 月 29 日

专注助手（以下简称"扩展"）尊重用户隐私。本政策说明扩展收集哪些数据、如何使用和保护这些数据。

1. 收集的数据

  • 浏览活动记录：你访问的网站的域名、页面标题、浏览时长和活动时段，用于限额计时和本地统计。
  • 模型服务配置：你在偏好分析功能中主动填写的 API Key 和服务地址，仅用于你发起的连接测试与分析。

扩展不读取网页正文内容，不收集点击、滚动、击键、位置、通讯等数据。

2. 数据存储

所有浏览记录、限额规则和统计数据默认仅保存在你的浏览器本机。扩展没有自有服务器，不接收、不上传上述数据。API Key 同样只保存在本机。

3. 向第三方传输

只有你主动点击"开始分析"时，扩展才会把近 7 天最多 40 条活动记录（域名、页面标题、时长）连同你配置的 API Key 发送给你自行指定的第三方模型服务，用于内容分类与生成建议。连接测试不会发送任何浏览记录。该第三方服务由你自己选择并受其隐私政策约束。

除此之外，扩展不会向任何第三方出售或传输你的数据，不将数据用于广告、信用评估或与核心功能无关的目的。

4. 你的控制权

  • 在扩展的统计页可一键清除全部本地浏览历史。
  • 删除模型服务配置即删除已保存的 API Key。
  • 可以随时修改或删除任何限额规则。
  • 卸载扩展将删除其全部本地数据。

5. 联系我们

如对本政策有疑问，可通过扩展在 Chrome 应用商店发布页面中列出的联系方式与我们联系。
